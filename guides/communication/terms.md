# 沟通术语与缩写

缩写本身是什么、全称怎么写，按字母序查[缩写速查](abbreviations.md)。这页只聊容易用错的几个：同一个写法在不同语境下的意思，以及怎么说才不容易被误解。

| 写法 | 英文或来源 | 大白话 | 例子 / 容易误解的地方 |
|---|---|---|---|
| cc | Carbon Copy | 抄送，让某人也知道这件事 | `cc 小王`：小王也来看看；不等于把任务交给他 |
| CC | Claude Code（在特定讨论中） | Claude 的编程 Agent 产品 | `Codex 和 CC` 中通常指产品；`cc 某人` 通常是抄送 |
| LGTM | Looks Good To Me | 我看着没问题 | 是审查意见，不等于已经合并，也不保证没有 bug |
| IT | Information Technology | 信息技术 | 软件开发是其中一部分 |
| toB / B2B | Business to Business | 面向企业客户 | 不代表只能由团队使用 |
| ASAP | As Soon As Possible | 尽快 | 没有具体截止时间，最好补充时间、优先级和依赖 |
| TL;DR / TLDR / TL DR | Too Long; Didn’t Read | 长文的简短摘要，也可能表示没读长文 | 放在文首一般是摘要；单独回复别人可能显得不礼貌 |
| WIP | Work In Progress | 还在做 | 不等于已可验收 |
| ETA | Estimated Time of Arrival | 预计到达或完成时间 | 是估计，不自动等于承诺 |

这些是通用补充，不代表每个词都已在社区出现。聊天或评审里的缩写要分清语境，LGTM 不能替代仓库要求的正式审查。更多缩写见[缩写速查](abbreviations.md)。
